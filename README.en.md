A simple and handy tool for recording and replaying mouse and keyboard actions.

## ✨ Features

*   🎥 **Action recording**: clicks, mouse moves and key presses.
*   ▶️ **Playback**: exact replay via hotkey, with a finish sound.
*   📂 **Sessions**: save, load, rename, folders; clicking a folder never wipes the panel.
*   ⌨️ **Hotkeys**: assign keys to launch macros.
*   🪟 **Single instance**: relaunching shows the already open window.
*   ⚙️ **Interface settings**: font size (10–20 pt), Windows autostart, start minimized to tray.
*   🌑 **Dark theme**: One Dark palette, Tahoma font, role-colored buttons.
*   🎒 **Portability**: the app folder can be moved between machines.

## 🚀 Install and run

1.  Download the installer from the [latest Macro Recorder release](https://github.com/Frommer-droid/Macro-recorder/releases/latest).
2.  Run the installer and select the application folder.
3.  Open Macro Recorder using the shortcut. The application folder remains portable.

Requirements: Windows 10/11, AutoHotkey v2 (for playback hotkeys).
