<h1 align="center">Macro Recorder</h1>

Простой и удобный инструмент для записи и воспроизведения действий мыши и клавиатуры.

## ✨ Возможности

*   🎥 **Запись действий**: клики, движения мыши и нажатия клавиш.
*   ▶️ **Воспроизведение**: точное повторение по горячей клавише, со звуком окончания.
*   📂 **Сессии**: сохранение, загрузка, переименование, папки; клик по папке ничего не затирает.
*   ⌨️ **Горячие клавиши**: назначайте клавиши для запуска макросов.
*   🪟 **Один инстанс**: повторный запуск показывает уже открытое окно.
*   ⚙️ **Настройки интерфейса**: размер шрифта (10–20 pt), автозапуск Windows, запуск свёрнутым в трей.
*   🌑 **Тёмная тема**: палитра One Dark, шрифт Tahoma, ролевые цвета кнопок.
*   🎒 **Портативность**: папку с приложением можно переносить между устройствами.

## 🚀 Установка и запуск

1.  Скачайте установщик со страницы [последней версии Macro Recorder](https://github.com/Frommer-droid/Macro-recorder/releases/latest).
2.  Запустите установщик и выберите папку приложения.
3.  Откройте Macro Recorder через созданный ярлык. Папку приложения можно переносить.

Требования: Windows 10/11, AutoHotkey v2 (для горячих клавиш воспроизведения).
