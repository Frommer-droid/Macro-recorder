# История изменений (Release Notes)

## Версия 0.3.0 (2026-09-17)

*Единое оформление, защита от второго экземпляра и улучшения записи и воспроизведения.*

### ✨ Новые возможности

- **Обязательная тема оформления**: палитра One Dark, шрифт Tahoma, ролевая система кнопок (primary/danger/success/warning/neutral), правило геометрии «ширина ≥ высоты».
- **Один инстанс**: повторный запуск показывает уже открытое окно вместо дубликата.
- **Звук окончания**: после воспроизведения сессии проигрывается `Assets/stop.mp3`.
- **Русская локаль Qt**: стандартные меню и диалоги на русском (`qtbase_ru.qm` в поставке).
- **Автозапуск в меню**: пункты «Автозапуск» и «Запуск свёрнутым» переехали в выпадающее меню «Настройки».
- **Лицензия MIT** (`LICENSE`), английская версия документации (`README.en.md`).

### 🛠 Улучшения

- Левая панель и таблица не прыгают при кликах по папкам/сессиям: клик по папке вообще ничего не затирает, ширины замораживаются.
- Колонки таблицы — по контенту (X/Y минимум под 4 цифры координат); колонка «Клавиша» в дереве сессий больше не растягивается на полдерева.
- Подписи «Клавиша»/«Заголовок окна» над полями, кнопки «Начать запись» и «Сохранить» внизу панели.
- Сборка больше не запускает приложение автоматически (`post_build.py`).

### 🐛 Исправления ошибок

- Убрано двойное окно при повторном запуске (следствие отсутствия single-instance).
- Нейтральные кнопки больше не сливаются с фоном.

## Версия 0.2.0 (2025-12-06)

*Настройка размера шрифта, автозапуска и запуска в трей.*

### ✨ Новые возможности

- **Настройки интерфейса**: Добавлена кнопка "Настройки" в верхней панели.
- **Размер шрифта**: Теперь можно менять размер шрифта интерфейса (от 10 до 20 pt) через меню настроек. Выбранный размер сохраняется между запусками.

### 🐛 Исправления ошибок

- **Скрипт перемещения (`00_Move.pyw`)**:
    - Добавлена защита от ошибок доступа (`[WinError 5] Access Denied`).
    - Скрипт теперь корректно завершает процесс `MacroRecorder.exe` перед обновлением.
    - Добавлена обработка файлов "только для чтения".
- **Скрипт релиза (`00_CrRel.pyw`)**:
    - Исправлен источник файлов: теперь архив создается из установленной версии (`Portable Soft`), так как файлы перемещаются туда после сборки.
    - Исключена папка `Sessions` из архива релиза (чтобы не затирать данные пользователя).

### 📚 Документация

- Обновлены инструкции `RELEASE_SCRIPT_GUIDE.md` и шаблоны скриптов для соответствия новому процессу релиза.
